# ⚠️ Installation Guide

If your phone blocks installation:

- Open **Settings**
- Go to **Security**
- Enable **Install Unknown Apps**
- Install the APK again

# 🎯 How To Play

- Black moves first
- Trap opponent disks between your disks
- Captured disks flip to your color
- Player with the most disks wins 🏆
